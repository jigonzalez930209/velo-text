# Playground

Interactive playground with all features — see `/playground/` (Vite app).

Run:

```bash
pnpm run playground:dev  # or pnpm --filter playground dev
```

Features: edit paragraphs, headings, variables `&#123;&#123;name&#125;&#125;` (atomic), tables (Tab, spans), images (drag-drop, paste), LaTeX inline/block (`E=mc^2`, `\\frac{a}{b}`), exports PDF/ODT/DOCX, theme switcher, plugin sandbox.

See `playground/` and `examples/`.
